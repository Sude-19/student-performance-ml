# Student Performance Prediction

## About the Project
This project explores student performance data and applies machine learning models to predict exam scores. It was developed as part of my learning journey in data science and machine learning.

## Dataset
The project uses the Student Performance dataset from Kaggle.

- Target variable: `Exam_Score`
- Dataset size: 6,607 rows and 20 columns

- Ridge Regression

## Results
The Linear Regression model achieved an R² score of approximately 0.714 on the evaluation set.

Model performance depends on the preprocessing steps and train-test split. See the project code and analysis for details.
